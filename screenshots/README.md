# Screenshots

Add your screenshots here with the following names:

- `banner.png` - Banner image (optional, 800x200 recommended)
- `treemap-view.png` - Treemap view screenshot
- `list-view.png` - List view screenshot
- `split-view.png` - Split view screenshot
- `computer-view.png` - Computer/drive selection view
- `settings.png` - Settings dialog

## How to take screenshots

1. Run the application: `dua --path "C:\"`
2. Press `Tab` to switch between views
3. Use Windows Snipping Tool or `Win+Shift+S` to capture
4. Save with the names listed above

Recommended resolution: 800x600 or higher
